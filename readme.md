## ▶️ Como executar

Esta seção apresenta as instruções para executar as atividades desenvolvidas em Dart e os mini projetos construídos com Flutter neste repositório.

### 📋 Pré-requisitos

Antes de executar qualquer atividade, certifique-se de ter instalado:

- [Git](https://git-scm.com/)
- [Dart SDK](https://dart.dev/get-dart)
- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Um editor de código de sua preferência, como [Visual Studio Code](https://code.visualstudio.com/) ou [Android Studio](https://developer.android.com/studio).

Para verificar se as ferramentas estão instaladas corretamente, execute:

```bash
git --version
dart --version
flutter --version
flutter doctor
```


### 🟡 Executando atividades Dart

As atividades desenvolvidas em Dart ficam organizadas em seus respectivos diretórios dentro da pasta `dart/`.

**1. Acesse o diretório da atividade desejada:**

```bash
cd dart/<nome-da-atividade>
```

**2. Execute o arquivo principal da atividade:**

```bash
dart run main.dart
```

Caso o arquivo principal tenha outro nome, substitua `main.dart` pelo nome correspondente.

### 🔵 Executando mini projetos Flutter

Os mini projetos desenvolvidos com Flutter ficam organizados dentro da pasta `flutter/`. Cada projeto possui sua própria estrutura e gerenciamento de dependências.

**1. Acesse o diretório do mini projeto:**

```bash
cd flutter/<nome-do-projeto>
```

**2. Instale as dependências necessárias:**

```bash
flutter pub get
```

**3. Verifique os dispositivos disponíveis para execução:**

```bash
flutter devices
```

**4. Execute a aplicação:**

```bash
flutter run
```

Caso deseje executar em um dispositivo específico:

```bash
flutter run -d <device_id>
```

### 🛠️ Comandos úteis

| Comando | Descrição |
|---|---|
| `dart --version` | Exibe a versão instalada do Dart. |
| `dart run main.dart` | Executa uma atividade Dart. |
| `flutter --version` | Exibe a versão instalada do Flutter. |
| `flutter doctor` | Verifica a configuração do ambiente Flutter. |
| `flutter pub get` | Instala as dependências do projeto Flutter. |
| `flutter devices` | Lista os dispositivos disponíveis. |
| `flutter run` | Executa uma aplicação Flutter. |
| `flutter clean` | Limpa arquivos de build e cache do projeto. |
| `flutter pub upgrade` | Atualiza as dependências respeitando as restrições do projeto. |

> **Observações:**
>
> - Cada atividade Dart pode ser executada independentemente das demais.
> - Cada mini projeto Flutter possui seu próprio arquivo `pubspec.yaml`.
> - Para executar aplicações Flutter, é necessário ter um emulador aberto ou um dispositivo físico conectado.
> - Os comandos devem ser executados no terminal, respeitando o diretório de cada atividade ou projeto.
> - Substitua os valores entre `< >` pelos nomes e identificadores correspondentes.
